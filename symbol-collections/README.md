# Symbol collections

This directory owns public collection policy and discovery metadata for the canonical primitive-vector symbols implemented by `AIMORAPlatform/AIMORASymbols`.

`manifest.toml` pins the exact Platform revision, identifies the system baseline, and defines user and project collection scopes without copying geometry. The Studio may search stable IDs, names, asset classes, and accessibility descriptions; user and project collections store references to canonical symbol IDs and never duplicate engineering semantics or primitive sources.

The baseline artwork is independently authored AIMORA content under the repository licence. No vendor symbol library, traced artwork, canonical SVG, or private source is included.
